# Scenarios

Researched practice packs. Each folder is one scenario, generated by the agents in
[`agents/`](../agents/) and read by the app at request time.

```
scenarios/
  amazon-system-design/
    research.md    phase 1 — the dossier, every claim bucketed and sourced
    briefing.md    phase 2 — the report you read before practising
    pack.json      the pack the app loads: questions, timing, rubric
```

## Generating one

In Claude Code, from the project root:

```
/prep system design interview at Amazon
```

Then reload the app. The pack appears in the Knowledge tab tagged **researched**, and the
report is in the Briefing tab. No rebuild, no restart — [`/api/scenarios`](../src/app/api/scenarios/route.ts)
reads this directory on every request.

## What the app does with a pack

| File | Read by | Used for |
|---|---|---|
| `pack.json` → `questions` | Knowledge tab | The question list, filtered by level |
| `pack.json` → `notes` | Notes field | Ground truth the coach may not contradict |
| `pack.json` → `briefing` | Briefing tab | The report |
| `pack.json` → `briefing.rubric` | **the coaching prompt** | Your takes are scored against these dimensions instead of the app's generic ones |
| `research.md`, `briefing.md` | you | Reading on GitHub. The app renders from `pack.json`. |

That fourth row is the point of the whole pipeline. Everything else is context; the rubric is
what changes the score you see.

## If a pack does not show up

The Knowledge tab lists any scenario that failed to load, with the reason — `briefing.rubric[0].weight
must be high|medium|low`, or `no pack.json yet — the prep pipeline has not finished phase 2`.
Validation lives in [`src/lib/scenarios.ts`](../src/lib/scenarios.ts). To check a pack against
the schema directly:

```bash
npx ajv-cli validate -s agents/pack.schema.json -d "scenarios/*/pack.json" --spec=draft2020
```

Folders starting with `.` or `_` are ignored, which is a convenient way to park a
work-in-progress scenario without it appearing in the app.

## Keep these scenario-shaped

A pack describes **a round**, never **a person**. `notes` is a template telling whoever loads
it what ground truth to paste in — it must not contain anyone's résumé, visa status, employer
details, or compensation.

Your own background belongs in the app's Notes field. That lives in your browser's
localStorage and never touches this repo.
